# SecondEntryES for NinjaTrader 8

Clean-room, discretionary NinjaTrader 8 indicator for ES 2,000-tick charts.
It marks `2EL`, `2ES`, `F2EL`, and `F2ES` price-action events. It never places orders.

## Quick start

1. Download [`SecondEntryES-NinjaTrader8.zip`](https://github.com/Guangshuai/es-second-entry-nt8/releases/latest/download/SecondEntryES-NinjaTrader8.zip).
2. In NinjaTrader 8, choose **Tools → Import → NinjaScript Add-On** and select the ZIP.
3. Open an ES 2,000-tick chart, add **SecondEntryES**, then use Playback or Market Replay.

See [installation](docs/INSTALL.md) and [settings](docs/SETTINGS.md). This is an analysis tool, not trading advice; test in simulation before relying on any signal.
