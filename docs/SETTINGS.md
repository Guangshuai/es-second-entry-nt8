# Settings

- **Pivot Strength 2:** confirms the swing high/low that anchors each count. A count starts at the latest confirmed swing rather than at the EMA.
- **Break Offset 1 tick:** break required after the completed signal bar.
- **Strict Signal Bars:** requires body ≥40% and a close in the directional 30% zone.
- **Reset On Equal Extremes:** equal extreme is treated as a reset when enabled.
- **Failure Window 5 bars:** a triggered 2EL/2ES becomes failed only if its opposite signal extreme breaks in this window.
- **Labels:** `1EL`/`1ES` mark the first attempt; `2EL`/`2ES` mark the second. `HL`/`LH` identify a better second pullback; `DT` identifies a non-HL/non-LH second test. Projection lines are not drawn.
